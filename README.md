# L-I-NGUY-N-NG-I-N
Cổng đền: Giải mật mã ngoài rừng rậm tăm tối.  Sân đền: Thắp sáng đèn dầu giữa làn sương mù và tượng thần hộ pháp.  Hành lang: Đối mặt với ánh đèn đỏ máu và những màn hù dọa (jump-scare) bất ngờ.  Điện thờ: Giải phép tính phong ấn cuối cùng và chạy trốn cuộc truy đuổi nghẹt thở của bức tượng thần khổng lồ.
